Search Visibility Strategy

전국 어디서든 “반려동물 행사 = GWAA”가
검색·AI·추천에서 먼저 뜨게

강원을 넘어 경기·충청, 그리고 전국으로. 이미 청주(충북)·가평(경기)·원주·강릉·고성(강원)에서 행사를 성공시켜온 실적이 있으니, 검색·AI·추천도 전국구로 잡습니다. 핵심 연료는 구조화 데이터 + 실제 평판(후기·언론).

ChatGPT·Perplexity·Gemini가 “우리 동네 반려행사?”(전국 어디든)에 GWAA를 언급.

셋의 공통 기반은 같습니다 → ① 명확한 엔티티(우리가 누구·무엇을 하는지) ② 기계가 읽는 구조화 데이터(JSON-LD) ③ 남들이 우리를 언급·추천하는 평판. 아래는 그걸 GWAA에 심는 실행안입니다.

01SEO — 기술 & 콘텐츠 토대

지금 사이트는 Next 16이라 기본기는 좋습니다(SEO 점수 100 확인). 빠진 건 페이지별 메타·구조화·아이콘과 행사 상세를 랜딩으로 키우는 콘텐츠.

기술 SEO 체크리스트

  • P1 행사/클래스마다 고유 title·description·og:image — 현재 홈 위주. 상세는 “행사명 + 지역 + 날짜 + 무료/유료”가 제목에 들어가게.
  • P1 아이콘·manifest 404 해결 — apple-icon, manifest 등 6개 404(분석 리포트). 홈화면 저장·PWA·신뢰도.
  • P1 동적 sitemap.xml에 모든 행사/아카이브 URL + lastmod. 종료 행사도 아카이브로 유지(축적된 URL이 자산).
  • P2 이미지 alt에 “행사명·지역·반려동물” 서술. webp·lazy(대부분 적용됨).
  • P2 헤딩 순서 h1→h2→h3 정상화(분석서 h2→h4 스킵 발견). 접근성=SEO.
  • P2 내부 링크: 홈→행사, 행사→관련 클래스/셀러/후기 상호 연결(고아 페이지 방지).
  • P3 Core Web Vitals: 펫스카웃 랜딩 16,000px·자동영상 LCP 관리, 모션 조건부 로드.

콘텐츠 SEO — “행사 상세를 검색 랜딩으로”

  • 전국 키워드 + 도시별 랜딩(핵심 전략): ①전국 키워드 “반려동물 행사·축제·박람회”, “반려견 캠핑/트레킹”을 상위 페이지에서 선점. ②그 아래 도시별 페이지를 템플릿으로 대량 복제 — “청주 반려동물 행사”, “가평 반려견 축제”, “강릉·원주·고성 …”, 진출하는 도시마다 하나씩. 같은 틀·다른 지역명으로 롱테일을 전국에서 긁어옴.
  • 후기·리캡(Recap) 페이지: 끝난 행사마다 “N명 참가·사진·후기” 페이지 → 롱테일 트래픽 + 평판 축적.
  • 가이드 콘텐츠(전국): “반려견과 국내 여행 코스”, “반려동물 동반 축제 캘린더(전국)”, “지역별 반려동물 동반 카페·해변” → 검색 유입 깔때기 상단, 지역 무관하게 유입.

02구조화 데이터(JSON-LD) — 세 전선의 공통 연료

가장 ROI 큰 작업. 행사에 Event 스키마를 넣으면 구글이 날짜·장소·가격·잔여를 리치 결과로 보여주고, AI·생성엔진도 이 구조를 그대로 인용합니다.

① 행사 상세 — Event

{
  "@context":"https://schema.org",
  "@type":"Event",
  "name":"2026 강릉시 반려동물 문화행사 「올림펫」",
  "startDate":"2026-10-17T10:00+09:00",
  "endDate":"2026-10-17T17:00+09:00",
  "eventStatus":"https://schema.org/EventScheduled",
  "eventAttendanceMode":"https://schema.org/OfflineEventAttendanceMode",
  "location":{"@type":"Place","name":"강릉종합운동장 야외공연장",
    "address":{"@type":"PostalAddress","addressRegion":"강원","addressLocality":"강릉","addressCountry":"KR"}},
  "image":["https://gwaa.or.kr/images/events/olimpet-2026/poster.webp"],
  "organizer":{"@type":"Organization","name":"강원도반려동물협회","url":"https://gwaa.or.kr"},
  "offers":{"@type":"Offer","price":"0","priceCurrency":"KRW",
    "availability":"https://schema.org/InStock","url":"https://gwaa.or.kr/events/4"}
}

→ 종료 시 eventStatus를 EventScheduled/Postponed/Cancelled로 갱신. 이미 lib/eventStatus.ts가 상태를 아니 그 값을 스키마에 그대로 연결.

② 협회 — Organization(NGO)

  • Organization(또는 NGO)에 이름·로고·sameAs(인스타·유튜브·네이버·카카오채널) → 구글 지식패널과 엔티티 인식의 핵심.
  • 전국·글로벌 확장 시 이 엔티티가 “GWAA는 무엇인가”의 단일 출처가 됨.

③ 그 외 필수

  • BreadcrumbList(경로), FAQPage(아래 AEO), ImageObject(포스터), Review/AggregateRating(아래 평판).

03AEO — 답변엔진(구글 AI·스니펫)이 인용하게

사람들은 “강릉 반려동물 행사 언제야?”처럼 질문으로 검색합니다. 그 질문에 짧고 명확한 답을 페이지에 심으면 AI Overviews·피처드 스니펫이 GWAA를 끌어씁니다.

  • 행사/클래스마다 FAQ 블록(“참가비는?”, “반려견 없어도 되나요?”, “주차는?”) + FAQPage 스키마. 펫스카웃엔 이미 FAQ가 있으니 스키마만 붙이면 됨.
  • 핵심 사실을 페이지 상단 한 문장으로: “2026 올림펫은 10월 17일 강릉종합운동장에서 열리는 무료 반려동물 문화행사입니다.” — 스니펫이 통째로 인용.
  • 신청 방법을 번호 단계(1·2·3)로 → “How-to” 형식이 답변에 잘 뽑힘.
  • 날짜·장소·가격을 표로도 제공(기계 파싱 쉬움).

04GEO — 생성형 AI(ChatGPT·Perplexity·Gemini)가 언급하게

생성형 엔진은 “여러 곳에서 일관되게 언급되는 신뢰 엔티티”를 인용합니다. 우리 사이트 밖 존재감이 관건.

  • 엔티티 일관성(NAP): 이름·주소·연락처를 사이트·네이버플레이스·인스타·보도자료에서 토씨까지 동일하게. 생성엔진이 “같은 조직”으로 묶음.
  • 제3자 언급 확보: 지역 언론 보도, 시·군 보도자료, 참가 블로그·후기, 나무위키/위키 항목 → LLM 학습·인용원. “사람들이 잘한다고 말해주는” 걸 웹에 남기게 유도(후기 캠페인).
  • 사실을 구조화·평문으로: “2021년 창립, 누적 4만명+, 강원·경기·충청 등 전국 다수 지역, 90회+ 행사” 같은 팩트를 소개/보도자료에 명시 → 그대로 인용됨. (Organization에 areaServed를 ‘대한민국/다지역’으로 명시)
  • llms.txt(루트에 배치): 사이트 핵심·주요 링크를 LLM용으로 요약 제공(신흥 표준).
  • Bing/네이버도 챙기기: Perplexity·Copilot은 Bing 인덱스 의존 → Bing Webmaster 등록.

05평판(E-E-A-T) — “사람들이 잘한다고 말해주는” 걸 자산으로

이게 세 전선 모두의 최종 부스터. 구글은 경험·전문성·권위·신뢰(E-E-A-T)를, AI는 “남들이 추천하는 증거”를 봅니다. 지금 입소문이 웹에 안 남아 손해입니다.

  • 후기 수집·표시 + Review/AggregateRating 스키마: 참가자 별점·후기를 행사·협회 페이지에 → 검색결과에 ★별점 노출(CTR↑), AI가 “평 좋음” 근거로 인용.
  • 언론보도·성과 아카이브: 보도·수상·MOU·시군 협력, “3,500명 참가” 등 숫자를 소개 페이지에 로고·링크와 함께.
  • 파트너/후원사 로고 노출(이미 셀러/후원 존재) → 권위 신호.
  • 후기 유도 루프: 행사 후 카톡/메일로 “한 줄 후기 + 사진” 요청 → 사이트 리캡·구글 리뷰·인스타로. 입소문을 검색가능한 콘텐츠로 전환.
  • 작성자/주최 신원 명시(누가 운영·전문성) — 공신력 페이지 강화.
