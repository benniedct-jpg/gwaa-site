## 0. 한 장 요약 (지금 당장 손봐야 할 5가지)

| # | 문제 | 지금 상태 | 효과 |
|---|------|-----------|------|
| 1 | **`/classes`가 죽은 페이지** | 열자마자 이름·연락처 폼, 그 아래 모든 클래스가 "지난 타임"(펫스카웃 종료). 실제 신청 가능한 건 상시 아로마 1개뿐 | 클래스 신청 전환 ≈ 0 |
| 2 | **셀러·멤버십이 폼부터 들이댐** | 혜택·자격·심사일정·과거 부스 사진 없이 바로 입력폼 | 신청 이탈 |
| 3 | **메이트십 vs 멤버십 용어 혼선** | 설득 콘텐츠는 `/mateship`(잘 만듦)에, 실제 가입은 `/membership`(휑함)에 분리. 네비에도 둘 다 존재 | 가입 동선 붕괴 |
| 4 | **모바일 예약에 상시 고정 CTA·긴박감 없음** | 펫스카웃 예약 페이지에만 D-day 바가 있고, 나머지 행사·상세엔 하단 고정 예약바 없음 | 인앱 이탈 |
| 5 | **홈/데스크톱 히어로 과한 여백 + 아이콘 404** | 데스크톱 히어로 우측 60% 공백, apple-icon·manifest 등 404×6 → iOS "홈 화면 추가" 아이콘 깨짐 | 첫인상·PWA |

> 공통 진단: **콘텐츠·설계는 이미 상당히 좋다**(행사 상세, 메이트십 랜딩, 소개 페이지 수준 높음). 문제는 ①행사 종료 후 페이지가 자동으로 "빈 상태/과거 상태"로 방치되는 것, ②전환 동선(폼 우선·CTA 부재·용어 혼선), ③디자인이 그린 단색으로 다소 밋밋한 것. 큰 리뉴얼보다 **운영 자동화 + 전환 손질**이 ROI가 크다.

## 1. 계측 결과 (근거 데이터)

### 콘솔 / 리소스
- **홈 404 × 6** — `apple-icon.png`, `icon.png`, `manifest.json`, `site.webmanifest`, `favicon-32x32.png`, `favicon-16x16.png` 전부 404. (`/og-image.png`·`/favicon.ico`는 200)
  → iOS/안드로이드 **홈 화면 추가 시 아이콘 깨짐**, PWA manifest 부재. 카톡·인스타에서 들어와 저장하는 주 동선에 직접 타격.
- **401 × 1** — 관리자 인증 체크로 추정. 사용자 영향 없음(무해).

### Lighthouse (모바일, navigation)
| 항목 | 점수 |
|------|------|
| SEO | **100** |
| Accessibility | **94** |
| Agentic Browsing | 98 |
| Best Practices | **73** ⚠ |

Best Practices 73으로 떨어진 이유 = **콘솔 404 에러** + 서드파티 쿠키(카카오 채널 위젯). 아이콘/manifest만 채워도 크게 오른다.

**실패한 개별 감사(고쳐야 할 것):**
- Browser errors were logged to the console → 위 404
- Background/foreground **색 대비 부족** (그린 톤 위 옅은 텍스트 또는 muted gray 의심)
- **Heading 순서 비순차** (h1→h3 건너뜀) → 스크린리더·SEO 구조
- Uses third-party cookies (카카오 위젯)

> LCP/CLS 정량치는 이 모드에서 제외됨. 별도 `performance_start_trace` 권장. 정성적으로는 **펫스카웃 랜딩 16,000px·자동재생 영상**, **홈 히어로 캐러셀**이 LCP·데이터 부담 요인.

## 2. 페이지별 문제점 (캡처 근거)

### 🏠 홈 `/` — `01-home-375.png`, `07-home-1440.png`
- **데스크톱 히어로가 휑함**: 좌하단에 헤드라인/CTA만, 우측 ~60%가 흰 여백 + 미세한 파티클 점뿐. 히어로 비주얼(반려견 사진/일러스트)이 없어 "미완성" 인상.
- 히어로가 **자동 회전 캐러셀**(교육/… 슬라이드). 캐러셀은 참여율이 낮고 첫 슬라이드만 대개 소비됨 → 핵심 메시지가 회전에 묻힘.
- 모바일 풀페이지에 **중간 큰 공백**(메이트십 혜택 미리보기·행사 미리보기 섹션이 스크롤 전엔 비어 보임). `whileInView` 애니메이션 + 지연 로딩 이미지가 빠른 스크롤에서 늦게 뜸.
- 상단 숫자 지표(40,000+/90회+/18+/5년+)는 좋음 — **공신력 신호로 잘 작동**.

### 🎪 행사 목록 `/events` — `02-events-375.png`
- **콘텐츠 자체는 우수**: 다가오는 행사 카드 + 연도별 아카이브(2026~2021) 필터, "자리 맡기" CTA. 실제 링크 20+개 정상.
- 다만 아카이브 카드가 **지연 로딩 이미지 + 애니메이션**이라 빠른 스크롤 시 하단이 "빈 페이지"처럼 보임(체감 문제).
- 상단 히어로 문구 "우리 매일 뭐 하고 놀지, 여기 다 있어요" — 톤 좋음.

### 📋 행사 상세 `/events/7` (무료 산책교육) — `03-eventdetail-top-375.png`
- **잘 만든 페이지**: 일러스트 히어로, 핵심 정보 표(교육기간·신청방법·모집인원·참가비·결과보고), UPCOMING/무료 배지, D-10 노출.
- CTA "햅삐 2기 신청하기"는 JS 버튼(모달/스크롤). **하단 고정 예약바 없음** → 4,000px 페이지에서 스크롤 중 CTA가 사라짐.
- 신청방법이 "강원도반려생활 홈페이지…" 텍스트 → **외부 이동인지, 내부 폼인지 모호**.

### ⛺ 펫스카웃 랜딩 `/events/3` — (캡처 생략, 16,072px)
- 데이 바이 데이 일정(DAY1/2/3), FAQ 아코디언, 사운드 토글 영상까지 **완성도 매우 높은 랜딩**. 다만 행사(9/4~9/6)가 이미 종료 → 예약 위젯·D-day 바가 숨겨져 CTA가 안 보임.
- 문제는 **종료 후에도 페이지가 "예약하러 왔는데 아무 버튼 없음" 상태**로 남는 것. 종료 시 "다음 회차 알림받기/후기 보기"로 자동 전환 필요.

### 🎓 클래스 `/classes` — `04-classes-top-375.png` 🔴 **가장 심각**
- 열자마자 **이름·연락처 입력폼**, 그 아래 클래스 리스트 **전부 "지난 타임"**(핸드팬·아크로요가·훌라·퍼피요가·애니멀플로우 = 펫스카웃 9/4~9/6 종료). 유일하게 신청 가능한 건 **상시 아로마 DIY 1개**.
- 코드(`lib/classesCatalog.ts`)가 **펫스카웃 2026에 하드코딩** → 행사 끝나면 카탈로그 전체가 과거로. 오늘 방문자는 **살 게 없는 결제 페이지**를 본다.
- 개인정보(이름·연락처)를 **뭘 살지 보기도 전에** 먼저 요구.

### 🛍 셀러 모집 `/sellers` — `05-sellers-top-375.png`
- 폼 자체는 깔끔(참가행사 선택, 기본정보, 카테고리, 후원물품 무료 / 2만원 택1, 인스타·사업자번호). **완주 가능한 좋은 폼**.
- 그러나 **폼 우선(form-first)**: 셀러 혜택, 부스 크기·위치, 예상 방문객, **심사 단계·기간·담당자**, 과거 프리마켓 사진이 폼 위에 없음. 셀러는 "여기 나가면 팔릴까? 언제 결과 나오나?"를 못 보고 이탈.

### 🤝 메이트십 `/mateship`
- **매우 잘 만든 혜택 랜딩**: "혼자 말고 우리랑", 40,000+ 반려인, 혜택 카드(숙박/카페/캠핑/행사 우선), 파트너 필터(호텔·리조트·공원·의료·사료·펫케어·식당), **내 절약액 계산기**, FAQ, 제휴 제안. — 사이트 최고 수준.
- 문제: 이 설득 콘텐츠와 **실제 가입(`/membership`)이 분리**. "월 1만원" CTA가 두 페이지에 중복.

### 💳 멤버십 가입 `/membership` — `06-membership-top-375.png`
- **휑한 가입 페이지**: 혜택이 "제휴처 할인·행사 할인·디지털 회원증까지" **한 줄**. 제휴처 목록·할인율·회원증 이미지·회원 수 등 설득 요소가 `/mateship`에만 있고 여기엔 없음.
- **용어 혼선**: 헤더는 "GWAA **메이트십** 회원가입", 버튼은 "**멤버십** 가입하기". 네비에도 `MATESHIP`과 별개로 `메이트쉽 가입`. 사용자는 "메이트십=멤버십=회원=회비"가 같은 건지 헷갈림.
- **가격 프레이밍**: "월 1만원" 크게, 실제는 "**연 12만원 일시결제**"(월 결제 없음) 작은 글씨. 오해 소지.
- CTA 2개 스택("멤버십 가입하기" 초록 + "카카오로 시작하기" 노랑)이 **어느 게 진짜 시작인지 위계 모호**. 바로 아래 로그인 폼까지 겹쳐 혼잡.

### 🐾 소개 `/about`
- **공신력 콘텐츠 탄탄**: VISION, 설립목적, 핵심가치(교육·나눔·연결·성장), 활동지역 18개 시군, 누적 4만명+, 주요사업 6개, 연혁 타임라인.
- 보강 여지: **언론보도·파트너/후원사 로고·NGO 재무 투명성(결산 공시)·임원진** — 협회 신뢰의 결정타가 빠짐.

### 📞 문의 `/contact`
- 잘 됨: KAKAO/PHONE/EMAIL/ADDRESS 카드 + 문의 폼 + "카톡 가장 빠름". 특별한 문제 없음.

### 🧭 전역 네비게이션
- 상단 네비 라벨이 **영문 전용**: ABOUT · EDUCATION · EVENTS · MATESHIP · TRAVEL · SUPPORT · CONTACT. 일반 반려인(고연령 포함) 대상 공공 NGO엔 **한글 병기/한글 우선**이 명확.
- **Classes·Sellers가 네비에 없음** → 클래스·셀러는 행사에 묻혀 유입 경로가 약함(행사 종료 시 더 고아가 됨).

## 3. 개선안 (우선순위 · 왜→어떻게→예상효과→난이도)

### 🔴 바로 효과 큰 것 (1~2주, 대부분 난이도 하~중)

**R1. 클래스 페이지를 "이벤트 종속"에서 "상시 카탈로그"로**
- 왜: 오늘 방문자가 전부 "지난 타임"인 죽은 결제 페이지를 본다.
- 어떻게: ①지난 타임은 **접거나 하단으로**, 신청 가능한 타임을 최상단에. ②신청 가능한 클래스가 0개면 "**다음 클래스 알림받기**"(카톡) + 다가오는 행사(올림펫·원주) 클래스로 자동 연결. ③이름·연락처 폼은 **클래스 선택 후**에 노출.
- 효과: 죽은 페이지 → 최소한 알림·다음 행사 유입. 클래스 전환 회복.
- 난이도: 중 (`classesCatalog`·`/classes` 상태 로직).

**R2. 홈·행사 아이콘/manifest 404 제거 + 헤딩 순서·대비 수정**
- 왜: iOS 홈화면 저장 아이콘 깨짐, Best Practices 73, a11y 대비·헤딩 실패.
- 어떻게: `apple-icon.png`·`icon.png`·`manifest.json`(또는 Next 메타데이터 `icons`/`manifest`) 채우기. h1→h2→h3 순서 교정. 저대비 텍스트 토큰 상향.
- 효과: BP 73→90+, PWA 저장 정상화, 접근성 개선.
- 난이도: 하.

**R3. 모든 예약형 페이지에 하단 고정 CTA 바(+정원·D-day)**
- 왜: 지금은 펫스카웃 예약에만 D-day 바. 무료 교육·상세 등은 스크롤 중 CTA 소실.
- 어떻게: 상세/예약 공통 **sticky 하단바** = "[신청/예약하기] · 남은자리 N · D-N". 마감 임박 시 색 전환(주황→빨강).
- 효과: 모바일 인앱 전환 +10~15%(레퍼런스: Eventbrite·Booking.com 표준).
- 난이도: 중.

**R4. 멤버십·메이트십 통합 + 용어 단일화**
- 왜: 설득은 `/mateship`, 가입은 `/membership`으로 쪼개지고 명칭이 섞여 동선이 깨짐.
- 어떻게: 용어를 **하나로**(권장: 대외 브랜드 "메이트십" 유지, 내부 라벨은 "회원가입"으로 통일). `/membership`에 **메이트십 핵심 혜택 3~4개 + 회원증 이미지 + 40,000+·절약액 요약**을 올리고, 네비 중복 제거.
- 효과: 가입 페이지 이탈 감소, 유료 전환 상승.
- 난이도: 중.

**R5. 가격 프레이밍·CTA 위계 정리(멤버십)**
- 왜: "월 1만원"↔"연 12만원 일시결제" 혼동, CTA 2개 위계 모호.
- 어떻게: "**연 12만원(월 1만원 꼴)**" 한 줄로 정직하게. 주 CTA 1개(가입) + 보조(로그인)로 위계 분리.
- 효과: 신뢰·완주율.
- 난이도: 하.

**R6. 셀러 페이지 폼 위에 "설득 블록" 추가**
- 왜: 혜택·심사일정 없이 폼부터 → 이탈.
- 어떻게: 폼 위에 ①셀러 혜택(무료/유료 차이·부스 사양), ②**심사 3단계·기간·담당자 연락처**, ③과거 프리마켓 사진 2~3장·후기.
- 효과: 신청 의욕↑, 문의 전화↓ (레퍼런스: 메가주·K-PET).
- 난이도: 하~중.

### 🟡 중간 (3~4주)

**Y1. 종료 행사 자동 전환** — 상세/랜딩이 끝나면 예약 위젯 자리에 "다음 회차 알림받기 + 후기·사진 + 관련 다가오는 행사"로 자동 교체(현재 `eventStatus.ts` 상태값 활용). 죽은 CTA 방지.
**Y2. 네비 정보구조 개편** — 한글 병기, `프로그램`(교육·클래스), `참여`(행사·셀러·프리마켓)로 그룹핑해 Classes·Sellers를 표면화.
**Y3. 행사 상세 신청방법 명확화** — "내부 폼 / 외부 이동" 아이콘·문구로 구분, 외부면 새 탭·복귀 안내.
**Y4. 소개 페이지 신뢰 강화** — 언론보도·파트너 로고 마퀴·재무/결산 공시 링크·임원진.
**Y5. 카톡 공유 미리보기 페이지별 최적화** — 행사/클래스 상세마다 og:image(포스터)·제목·잔여/일정 반영. 현재 홈 og만 확인됨.

### 🟢 장기 리뉴얼

## 4. 새로 넣으면 좋을 기능 5선 (레퍼런스 근거)

리서치(케이펫페어·메가주·쭈쭈쭈·Eventbrite·Booking.com·Gingr·한국동물보호협회) 기반.

1. **하단 고정 예약바 + 3중 긴박감(D-day·잔여좌석·마감카운트)** — 모바일에서 위(배너)·중앙(숫자)·하단(CTA) 반복 노출. → 인앱 전환 +10~15%. (Eventbrite / Booking.com)
2. **정원 + 자동 대기열 + 카톡 알림** — "6/8명", 마지막 2자리 색 전환, 마감 시 대기→취소분 자동 승격. → 완주·재유입. (Gingr)
3. **셀러 심사 진행 조회 대시보드** — 신청 후 "심사중(평균 3~5일)" 진행바 + 담당자 노출. → 문의 감소·이탈 방지. (메가주)
4. **후원자/회원 투명성 배지 + 결산 공시** — 최근 후원자·기부일·사용내역 공개(NGO 신뢰 + 2차 입소문). (한국동물보호협회)
5. **GWAA 포인트(인앱 캐쉬)** — 충전 후 행사·클래스·굿즈 원탭 결제. → 재방문·완주율↑, 수수료 절감. (쭈쭈쭈 "쭈머니")

(추가 후보: AI 선수요건 자동검증으로 클래스 즉시 승인/거절 — SchedulingKit)

## 5. 디자인 방향 3안 (현재 토큰 대비)

**현재 토큰(`app/globals.css @theme`):**
`--color-green #16a34a`(+hover #15803d/light #22c55e), 보조 blue #2563eb·amber #d97706, 배경 흰색·회색. 폰트 Noto Sans KR(본문)/Bebas Neue+Gothic(디스플레이). radius 6~20, shadow 은은.
**진단:** 일관성·공신력은 좋으나 **그린 단색이라 밋밋**하고, 보조색이 시스템색(파랑/주황)이라 브랜드 온기가 약함. 폼 페이지(클래스·셀러·멤버십)가 특히 "AI 기본 티".

| | A. 신뢰 그린+ (보수) | B. 강원 자연 듀오톤 (권장) | C. 요즘 감각 팝 (도전) |
|---|---|---|---|
| **컨셉** | 지금 그린 유지, 정돈만 | 그린 + 따뜻한 흙/모래 보조색 | 그린 유지 + 생기 액센트 + 큰 타이포 |
| **주색** | `#16a34a` 유지 | Forest `#1F7A44` (약간 딥) | `#16a34a` 유지 |
| **보조/액센트** | 뉴트럴 그레이 정리 | Sand `#E8DCC8` · Clay `#C9764F` · Sky `#7CB9C9` | Coral `#FF6B4A` · Cream `#FFF6E9` · Ink `#0E1B14` |
| **배경** | 흰색+`bg-soft` 계조 강화 | 웜 화이트 `#FBF8F3` | 화이트 + 다크 섹션 교차 |
| **폰트** | 현행 유지 | 헤드라인 Gothic A1 무게 대비↑, 본문 Noto | 헤드라인 Black Han Sans 초대형, 숫자 Bebas |
| **모션** | 최소 | 스크롤 페이드·패럴랙스 절제 | 마퀴·카운트업·뷰 트랜지션 |
| **느낌** | 공신력 100 / 신선 40 | 공신력 85 / 신선 80 | 공신력 65 / 신선 95 |
| **리스크** | 밋밋함 지속 | 낮음(토큰 추가만) | 톤 과하면 NGO 신뢰↓, 조판 관리 필요 |

- **권장: B안.** NGO 공신력을 유지하면서 강원(숲·해변·모래) 정체성으로 온기를 더함. **기존 토큰을 지우지 않고 보조 토큰만 추가**해 점진 적용 가능(리스크 최저). 폼·카드·CTA에 Sand/Clay를 얹으면 "AI 기본 티"가 즉시 빠짐.
- A는 안전하지만 현 불만(밋밋)을 못 푼다. C는 인스타 감각엔 최고지만 협회 신뢰와 한글 조판 관리 부담. → **B로 가고, 히어로·이벤트 배너 등 일부에 C의 대형 타이포/모션을 스팟 적용**하는 하이브리드 추천.
